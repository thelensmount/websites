# Websites

Public pages for our apps, published with GitHub Pages at https://forwardlog.app.
Each product has its own folder:

- `forwardlog/support/`: ForwardLog support (https://forwardlog.app/forwardlog/support/)
- `forwardlog/privacy/`: ForwardLog privacy policy (https://forwardlog.app/forwardlog/privacy/)

The site root and `forwardlog/` redirect to ForwardLog's support page.
`CNAME` sets the custom domain; `.nojekyll` publishes the files as they are.
